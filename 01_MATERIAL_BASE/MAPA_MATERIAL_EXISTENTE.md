## Archivos principales

| Archivo | Uso recomendado | Riesgo |
|---|---|---|
| `code_no_code_markdown_limpio.md` | Fuente principal para entender la charla y sus ideas | Puede contener marcas/personas reales y algunos problemas de encoding segun editor |

## Material que requiere saneamiento

- Datos de contacto personales o empresariales.
- Direcciones fisicas.
- Marcas comerciales.
- Nombres de empresas/personas.
- Cifras del caso si no hay autorizacion para publicarlas.
- Capturas de dashboard si contienen identidad visual o datos no publicables.

## Recomendacion de uso

Usar los documentos Markdown como fuente de escritura, no como texto final. La obra debe reescribir, ordenar, contextualizar y sanear el material.
