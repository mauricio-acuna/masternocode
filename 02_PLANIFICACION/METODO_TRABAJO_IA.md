# Metodo de trabajo con IA para esta obra

Este metodo replica lo aprendido en la obra Spotybank y lo adapta al material Code / No-Code.

## Principio central

La IA no debe inventar la obra. Debe ayudar a ordenar, desarrollar y verificar el material fuente.

## Ciclo recomendado por capitulo

1. Leer las diapositivas asociadas.
2. Extraer evidencia literal.
3. Identificar ideas centrales.
4. Separar inferencias de afirmaciones del caso.
5. Redactar con voz editorial.
6. Agregar tabla, checklist o ejercicio.
7. Revisar riesgos de marcas, permisos y claims.
8. Registrar notas de investigacion.

## Plantilla de prompt para redactar capitulos

```text
Actua como escritor tecnico y editor senior.
Usa el material fuente sobre Code / No-Code.
Redacta un capitulo claro, incisivo y aplicable.
Separa evidencia del caso, inferencias y recomendaciones.
No inventes datos.
No conviertas un resultado del caso en promesa universal.
Incluye tablas, criterios de decision y preguntas practicas.
Mantén tono tecnico, sobrio y persuasivo.
```

## Plantilla de prompt para revision

```text
Revisa este capitulo como editor tecnico.
Busca:
- afirmaciones absolutas sin evidencia,
- marcas o datos personales que requieran permiso,
- claims comerciales exagerados,
- falta de criterios de validacion,
- confusiones entre code, no-code, low-code y agentes,
- oportunidades para agregar tablas o checklists.
Devuelve hallazgos priorizados y cambios sugeridos.
```

## Reglas de escritura

- Usar ejemplos concretos.
- Explicar por que fallo cada enfoque sin caricaturizarlo.
- Mostrar que la IA depende de conocimiento estructurado.
- Mantener observabilidad y operacion como ejes.
- Distinguir sistema propio de sistema improvisado.
- Evitar prometer costos sin contexto.

## Unidad de calidad

Cada capitulo debe tener:

- Una tesis clara.
- Un caso o ejemplo.
- Una tabla o marco de decision.
- Riesgos.
- Preguntas para el lector.
- Cierre aplicable.
