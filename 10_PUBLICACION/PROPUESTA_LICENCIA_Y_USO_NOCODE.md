# Propuesta de licencia y uso

Este documento no reemplaza asesoramiento legal. Sirve para que la siguiente IA o editor no publique el material sin una decision minima.

## Decision pendiente

Antes de publicar, definir:

- Quien es el autor o titular de la obra.
- Si las diapositivas originales pueden reutilizarse.
- Si los nombres, marcas y contactos reales quedan visibles.
- Si el caso se presenta como real, anonimizado o recreado.
- Si el material sera gratuito, comercial o mixto.

## Opciones de licencia

| Opcion | Conviene cuando | Riesgo |
|---|---|---|
| Todos los derechos reservados | Se busca control comercial completo | Menor difusion |
| CC BY-NC-SA 4.0 | Se busca difusion educativa no comercial | Limita usos comerciales |
| CC BY 4.0 | Se busca maxima circulacion | Permite uso comercial de terceros |
| Licencia comercial propia | Se vendera como producto editorial | Requiere texto legal mas cuidado |

## Recomendacion inicial

Hasta resolver permisos, tratar todo el material como:

```text
Uso interno editorial. No publicar sin revision de permisos, marcas, nombres y datos de contacto.
```

## Restricciones

No publicar:

- Emails personales o comerciales sin decision.
- Direcciones fisicas.
- Capturas con identidad no autorizada.
- Logos o marcas si el uso no esta claro.
- Claims de costo/escala sin contexto.
