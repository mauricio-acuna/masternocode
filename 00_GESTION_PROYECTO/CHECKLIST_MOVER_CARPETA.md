# Checklist para mover la carpeta a otro IDE

Antes de mover:

- [ ] Cerrar el DOCX si esta abierto.
- [ ] Verificar si existe archivo temporal `.~lock...`; no es material editorial.
- [ ] Copiar la carpeta completa `suplemento`, incluyendo imagenes y subcarpetas nuevas.
- [ ] Mantener juntos los Markdown fuente y los DOCX.

Despues de mover:

- [ ] Abrir `README_OBRA_NOCODE.md`.
- [ ] Abrir `00_GESTION_PROYECTO/INSTRUCCIONES_PARA_OTRA_IA.md`.
- [ ] Crear repo Git nuevo para esta obra.
- [ ] Hacer commit inicial antes de editar.
- [ ] Decidir tratamiento de marcas/personas reales.
- [ ] Empezar por capitulo 1 del indice provisional.

No hacer todavia:

- [ ] Publicar imagenes sin revisar permisos.
- [ ] Publicar emails, direccion fisica o datos personales sin autorizacion.
- [ ] Presentar cifras del caso como promesa universal.
- [ ] Mezclar esta obra con Spotybank salvo como referencia conceptual saneada.
