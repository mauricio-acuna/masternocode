# Code No-Code

Manuscrito técnico-editorial sobre cómo diseñar, documentar y operar soluciones que combinan código, automatización y herramientas no-code.

## Estado

Proyecto editorial en desarrollo. El contenido se organiza por capítulos y materiales de gestión; no es un producto SaaS ni una formación terminada.

## Audiencia

Está dirigido a desarrolladores, perfiles técnicos y responsables de automatización que quieran evaluar cuándo conviene programar, configurar una plataforma o combinar ambos enfoques.

## Cómo leerlo

- `code_no_code_markdown_limpio.md`: versión consolidada para lectura.
- `00_GESTION_PROYECTO/`: decisiones, planificación y estado editorial.
- `09_REVISIONES/`: revisiones técnicas y editoriales.
- `10_PUBLICACION/`: materiales preparados para futuras versiones públicas.

## Límites

Los ejemplos y propuestas son material educativo y editorial. Deben validarse técnica, legal y operativamente antes de aplicarse en sistemas reales.

La licencia y las condiciones de publicación se definirán al cerrar la primera versión pública.
